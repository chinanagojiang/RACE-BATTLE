# RACE-BATTLE
一个C++写的卡牌小游戏
简介
种族大战 是一款在 Windows 控制台中运行的卡牌策略游戏。
玩家从 9 个种族 中选择一个，通过部署单位、移动、攻击、释放行动卡，与对手（AI 或玩家 2）对抗。
率先摧毁敌方总部（HQ）的一方获胜。

九大种族，各有独立被动与专属行动卡
3 × 5 战场布局，总部位于中央列
战士可多次攻击，其他职业一回合只能移动或攻击一次
战士和农民攻击时会受到反击
亡灵死亡有概率转化为骷髅
克苏鲁可令敌方攻击随机重定向
血族造成伤害回复生命，但总部每回合损失 1 点
支援双人对弈与 3 种 AI 难度
完整的 Buff / Debuff 系统（含中毒、燃烧、冻结、眩晕、疯狂等）
每族 5 张行动卡，共 45 张
纯文本控制台界面，无需图形库

编译与运行
用 Dev-C++ 新建一个 .cpp 文件，粘贴完整源码。

菜单栏 → 工具 → 编译选项 → 勾选「编译时加入以下命令」，输入：

text
-std=c++11
文件 → 另存为 → 编码选择 ANSI → 保存。

按 F11 编译并运行。

如果编译报错 This file requires compiler and library support for the ISO C++ 2011 standard，说明 -std=c++11 没有启用。

核心机制

行动点：用于部署、移动、攻击、使用行动卡。
补给值：每回合开始时，行动点重置为补给值。
每回合结束，补给值 +1。
每存活一个农民，回合结束额外 +1 补给。
除战士外，所有职业部署当回合无法移动或攻击。
战士没有召唤失调，部署当回合即可行动。

3. 行动次数
战士：可以多次攻击，但攻击后不能移动、移动后不能攻击。
其他职业：一回合只能选择移动或攻击一次。

4. 反击
只有战士和农民在攻击时会受到反击。
反击伤害由目标攻击力决定。
远程攻击（弓手、法师）不会触发反击。

5. 胜利条件
将敌方总部生命值降至 0 即可获胜。
总部被摧毁时游戏立即结束。

AI 行为说明
AI 每回合按以下顺序行动：

使用行动卡：扫描手牌，若付得起，则根据种族选择目标区域并使用。
抽牌：手牌未满时抽 1 张。
部署单位：从手牌中选择第一张付得起的牌，部署到后方（避开总部所在列）。
移动：将 1 个后排单位移向前线。
攻击：若范围内有嘲讽单位，必须优先攻击有嘲讽的单位。牧师攻击友方视为治疗
困难难度：优先攻击总部 → 攻击力最高的目标 → 避免被反击击杀。

普通 / 简单难度：按行顺序或随机选择目标。

常见问题
Q：编译时报错 This file requires compiler and library support for the ISO C++ 2011 standard？
A：在 Dev-C++ 的「工具 → 编译选项」中勾选「编译时加入以下命令」，填入 -std=c++11。

Q：中文显示乱码？
A：将源文件另存为 ANSI 编码，并在控制台字体中选择 Consolas 或黑体。

Q：为什么我的单位不能移动？
A：非战士单位部署当回合有召唤失调；冰冻、眩晕、疯狂等状态也会限制行动。

Q：如何查看 Buff 效果？
A：输入 ? 可在游戏内查看完整的 Buff / Debuff 说明。
